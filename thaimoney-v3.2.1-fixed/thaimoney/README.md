# ThaiMoney (v3.2.0) — Fabric / Minecraft Java

ระบบเงินสด + ATM + กระเป๋าสตางค์ + ตลาด + ประมูล + แผงตลาด + ตู้ขายของ ทำงานฝั่งเซิร์ฟเวอร์ GUI ใช้เมนูหีบของเกมเอง (ไม่มีโค้ดไคลเอนต์)

## Build / ติดตั้ง (Minecraft Java 26.3)

โปรเจกต์นี้มีไฟล์ Gradle แล้ว ไม่ต้องนำ `src` ไปวางทับ template อีกต่อไป

**เครื่องมือที่ต้องใช้**
- JDK 25 (ตั้ง `JAVA_HOME` ให้ชี้ไป JDK 25)
- Gradle 9.6.0 (เวอร์ชันที่ Fabric แนะนำสำหรับ Minecraft 26.3) หรือใช้สคริปต์ `build.ps1` บน Windows เพื่อดาวน์โหลด Gradle 9.6.0 อัตโนมัติ
- Minecraft Java 26.3, Fabric Loader 0.19.5+ และ Fabric API รุ่นที่ตรงกับ 26.3

**Build บน Windows 10/11** จาก PowerShell ในโฟลเดอร์โปรเจกต์:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build.ps1
```

สคริปต์จะตรวจ Java 25, ใช้ Gradle 9.6.0 (ดาวน์โหลดลง `.tools` หากไม่มี Gradle ใน PATH) และรัน `gradle build` พร้อม regression tests ของ core หากติดตั้ง Gradle ไว้แล้ว สามารถใช้ `gradle build` ได้โดยตรง

ไฟล์ mod จะอยู่ใน `build/libs/` ใช้ไฟล์ `thaimoney-3.2.0.jar` (ไม่ใช่ `-sources.jar`) แล้วนำไปใส่ `mods/` ของเซิร์ฟเวอร์และไคลเอนต์ที่ต้องการให้เห็นไอเทม custom พร้อมติดตั้ง Fabric API รุ่นตรงกันด้วย

> หมายเหตุ: การตรวจในสภาพแวดล้อมที่ใช้จัดทำแพ็กเกจนี้ผ่านเฉพาะ regression tests ของ core ด้วย JDK 21; ไม่สามารถยืนยันการ Build ตัวม็อดเต็มได้ เนื่องจากไม่มี JDK 25/Gradle และสภาพแวดล้อมไม่สามารถเข้าถึงอินเทอร์เน็ตเพื่อดาวน์โหลด dependencies ได้ จึงต้องรัน `build.ps1` บนเครื่อง Windows ที่มีอินเทอร์เน็ตเพื่อยืนยันการ Build เต็ม

## ทดสอบตรรกะเงิน (ไม่ต้องใช้ Minecraft)

รันพร้อมการ Build ด้วย `build.ps1` หรือใช้ `gradle coreTests` หากติดตั้ง Gradle แล้ว โดย Gradle จะคอมไพล์และรัน `CoreTest`, `CoreTest2`, `CoreTest3` และ `CoreTest4` อัตโนมัติ

## อัปเดต v3.2.0
- เพิ่ม Gradle project config สำหรับ Minecraft 26.3 / Java 25 / Fabric Loom
- ปรับการโอน ถอน และซื้อขายให้ตรวจยอดบัญชีทุกฝั่งก่อน commit ลดความเสี่ยงเงินถูกหักบางส่วนเมื่อเกิด overflow
- ปรับการบันทึก JSON ให้ใช้ atomic move เมื่อ filesystem รองรับ และ fallback เมื่อไม่รองรับ
- ปรับ metadata ให้ระบุเวอร์ชัน mod จาก Gradle และจำกัด Minecraft dependency ให้อยู่ในสาย 26.3

## ฟีเจอร์
- **เงินสด 9 ชนิด** (เหรียญ 1/2/5/10, ธนบัตร 20/50/100/500/1000)
- **ATM** (คราฟต์ได้) คลิกขวา → PIN 4 หลัก (แฮช+salt, ผิด 3 ครั้งล็อก 5 นาที) → ฝาก / ถอน / โอน / ประวัติ / เปลี่ยน PIN
- **กระเป๋าสตางค์** (คราฟต์: หนัง×8 + gold nugget) คลิกขวาเปิด
- **ร้านระบบ** `/shop` ราคาตามอุปสงค์อุปทาน แก้รายการใน `config/thaimoney_shop.json`
- **ตลาดผู้เล่น** `/market`, `/market sell <ราคา>` (ถือของในมือ) ภาษีขาย 3%
- **ประมูล** `/auction` (ซ้าย = เสนอขั้นต่ำ, Shift+ซ้าย = +10%, ขวา = ยกเลิกถ้ายังไม่มีผู้เสนอ)
  - `/auction start <ราคาเริ่ม> <นาที>` เปิดประมูลของในมือ, `/auction bid <รหัส> <จำนวน>`
  - เงินถูกกันไว้ทันทีและคืนอัตโนมัติเมื่อถูกเสนอสูงกว่า, ต่อเวลา 2 นาทีถ้าเสนอช่วงท้าย, ค่าธรรมเนียมผู้ขาย 5%
  - ผู้ชนะ/ผู้ขายรับของด้วย `/claim` (ใช้ได้แม้ออฟไลน์ตอนจบ)
- **แผงตลาด** `/stall`, `/stall rent day|week` (฿500/วัน, ฿3000/สัปดาห์) ระหว่างเช่า: ลงขายได้ 30 รายการ (ปกติ 10) และภาษีขาย 1% (ปกติ 3%)
- **ตู้ขายของ** เล็งที่หีบ ถือไอเทมที่จะขาย แล้ว `/chestshop create <ราคาต่อชิ้น>` เติมของในหีบ ผู้ซื้อคลิกขวา (Shift = 16 ชิ้น) เจ้าของเท่านั้นที่เปิด/ทุบหีบได้ `/chestshop remove` ยกเลิก
- **แท็บ Creative:** เงินสด+กระเป๋าสตางค์อยู่ในแท็บ "เครื่องมือและยูทิลิตี้", ATM อยู่ในแท็บ "บล็อกใช้งาน"
- **โซนตลาด (แอดมิน):** `/admin marketzone add <มุม1> <มุม2>` (ใช้พิกัด ~ ได้), `/admin marketzone list`, `/admin marketzone remove <เลข>`
  เมื่อมีโซนอย่างน้อย 1 โซน การลงขาย (`/market sell`) เปิดประมูล เช่าแผง และตั้งตู้ขายของ ทำได้เฉพาะตอนยืนในโซน (การซื้อ/เสนอราคาทำที่ไหนก็ได้) ถ้ายังไม่มีโซน = ไม่จำกัด
- คำสั่งอื่น: `/bal`, `/pay <ผู้เล่น> <จำนวน> [PIN]`, `/wallet`, `/admin money give|take|set <ผู้เล่น> <จำนวน>`
- ตั้งค่าทั้งหมดใน `config/thaimoney.json` ข้อมูลอยู่ใน `world/thaimoney/accounts.json` + `transactions.log`
- ทดสอบไอเทม: `/give @s money:note_100 5`, `/give @s money:atm`, `/give @s money:wallet`

## ข้อจำกัดที่ควรรู้
- ตลาด/ร้านระบบ/ประมูล/ตู้ขายของ รองรับเฉพาะ **ไอเทมธรรมดา** (ไม่มีชื่อ เอนแชนต์ หรือความทนทานลด)
- แผงตลาดเป็นระบบ "เช่าสิทธิ์" (ใช้ร่วมกับโซนตลาดเพื่อจำกัดพื้นที่)
- ตู้ขายของ: ใช้หีบเดี่ยว, ระเบิด/ฮอปเปอร์ยังทำลายหรือดูดของจากหีบได้ (ไม่ควรวางฮอปเปอร์ติดหีบ) ถ้าต้องการกันเพิ่มบอกได้
- โอนผ่าน ATM/`/pay` ได้เฉพาะผู้เล่นที่ออนไลน์
- เงินในกระเป๋าสตางค์ไม่ดรอปตอนตาย
- `/deposit` `/withdraw` ปิดไว้ ให้ใช้ ATM (เปลี่ยนที่ `requireAtmForCash`)
