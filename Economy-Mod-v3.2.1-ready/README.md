# ThaiMoney (Economy-Mod v3.2.1) — Fabric / Minecraft Java 26.3

ระบบเงินสดไทย (เหรียญ/ธนบัตรสมจริง) + ATM + กระเป๋าสตางค์ + ตลาดซื้อขาย + ระบบประมูล + เช่าแผงตลาด + ตู้ขายของ (Chest Shop) ทำงานฝั่งเซิร์ฟเวอร์ล้วน GUI ใช้เมนูหีบของ Minecraft ไม่ต้องลงม็อดฝั่งไคลเอนต์

## การดาวน์โหลดและ Build ไฟล์ `.jar`

### วิธีที่ 1: Build อัตโนมัติบน GitHub Actions (ง่ายที่สุด ไม่ต้องลงโปรแกรมในคอม)
โปรเจกต์นี้ตั้งค่า GitHub Actions ไว้ใน `.github/workflows/build.yml` แล้ว:
1. Push หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Repository ของคุณ
2. ไปที่แท็บ **Actions** บน GitHub เลือกเวิร์กโฟลว์ **Build ThaiMoney Mod (.jar)**
3. เมื่อสถานะขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 1–2 นาที) ให้เลื่อนลงไปที่หัวข้อ **Artifacts**
4. คลิกดาวน์โหลด **`thaimoney-fabric-26.3-jar`** จะได้ไฟล์ `thaimoney-3.2.1.jar` ไปใช้งานทันที

### วิธีที่ 2: Build เองบนเครื่อง Windows
1. ติดตั้ง **JDK 25** (ตั้งค่า `JAVA_HOME` ชี้ไปยัง JDK 25)
2. เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วรัน:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\build.ps1
   ```
3. สคริปต์จะใช้ Gradle 9.6.0 คอมไพล์ตัวม็อดและรัน Regression Tests ทั้งหมด
4. ไฟล์ม็อดสำเร็จรูปจะอยู่ที่ `build/libs/thaimoney-3.2.1.jar`

## ฟีเจอร์เด่น
- **เงินสดไทย 9 ชนิด (เท็กซ์เจอร์สมจริง)**:
  - เหรียญ 1 บาท (โลหะเงิน)
  - เหรียญ 2 บาท (โลหะทองเหลือง)
  - เหรียญ 5 บาท (โลหะเงิน)
  - เหรียญ 10 บาท (เหรียญสองกษัตริย์: วงนอกเงิน วงในทองเหลือง)
  - ธนบัตร 20 บาท (เขียว), 50 บาท (ฟ้า), 100 บาท (แดง), 500 บาท (ม่วง) พร้อมแถบฟอยล์กันปลอม
  - ธนบัตร 1,000 บาท (สีน้ำตาลเทา Taupe พร้อมแถบทองโฮโลแกรม)
- **ตู้ ATM (คราฟต์ได้)**: วางแล้วคลิกขวา ตั้ง PIN 4 หลัก ฝาก/ถอน/โอนเงิน ดูประวัติย้อนหลัง 30 รายการ
- **กระเป๋าสตางค์ (Wallet)**: คราฟต์จากหนัง 8 แผ่น + ก้อนทอง พกติดตัวแล้วคลิกขวาเพื่อเก็บหรือหยิบเงินสด
- **ร้านค้าระบบ (`/shop`)**: ราคาปรับขึ้นลงตามอุปสงค์และอุปทาน (Demand & Supply)
- **ตลาดผู้เล่น (`/market`)**: ซื้อขายสินค้าระหว่างผู้เล่น ป้องกันการโกง
- **ระบบประมูล (`/auction`)**: เปิดประมูลสินค้า แข่งกันเสนอราคา กันเงินประกันอัตโนมัติ
- **แผงตลาด (`/stall`)**: เช่าสิทธิ์ลงขายในตลาดได้มากขึ้นและลดภาษี
- **ตู้ขายของ (`/chestshop`)**: เปลี่ยนหีบให้เป็นตู้ขายของอัตโนมัติ
